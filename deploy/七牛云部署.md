# 在七牛云上部署主题商店（自有域名）

你已有域名，配合七牛云的**云服务器 / 轻量应用服务器**（国内、访问快、磁盘持久）是最稳的组合。下面是用你自己域名的完整路径。

## 1. 开一台七牛云云服务器
- 镜像选 **Ubuntu 22.04 / 24.04 LTS**（脚本针对 Debian/Ubuntu）。
- 配置：1 核 1G 起步即可（主题包很小），系统盘 20G 够用。
- 记下**公网 IP**。

## 2. 一键部署后端
SSH 进服务器，执行：
```bash
curl -fsSL https://raw.githubusercontent.com/huangjinkun2006/oc-theme-store/main/deploy/setup.sh | sudo bash
```
脚本会自动装 Docker、拉仓库、起容器（数据持久化在 `/var/lib/ocstore`）。
本地跑则：`sudo bash deploy/setup.sh`。

健康检查：`curl http://127.0.0.1:8000/api/health` 应返回 `{"ok":true,...}`。

## 3. 解析域名
在你的域名解析后台，添加一条 **A 记录**（或 AAAA 如果是 IPv6），主机记录如 `@` 或 `store`，指向七牛云服务器的**公网 IP**。等几分钟生效。

## 4. 反代 + HTTPS
把 `deploy/nginx.conf` 复制到服务器 `/etc/nginx/conf.d/oc-theme-store.conf`，并把里面的 `server_name your-domain.com` 改成你的域名，然后：
```bash
nginx -t && systemctl reload nginx
certbot --nginx -d 你的域名      # 自动签发并配置 HTTPS（需先装 certbot）
```

## 5. 可选：七牛云 CDN 加速
若想下载更快，可在七牛云 CDN 控制台把**源站**设为你的服务器（IP:80 或反代后的 80/443），开启 HTTPS + 缓存。主题包走 CDN 后国内访问会明显更快。

## 6. 回填到 App
部署完拿到 `https://你的域名` 后，发给我，我把这个地址写进 macOS App 的**默认服务器地址**并重新打包，其他用户下载 app 即可开箱连上，无需手填。

---

### 备案说明
国内服务器 + 自定义域名做公开 Web 服务，按规定需要 **ICP 备案**。七牛云/接入商一般提供备案通道；备案期间可用 IP 临时访问，正式域名访问建议备案完成后再全量开放。

### 数据持久性
主题数据落在服务器磁盘 `/var/lib/ocstore`，重启/重装容器都不丢。务必**定期快照或备份该目录**。若想连存储也交给七牛，可让我改造后端把文件存进七牛云 Kodo 对象存储（见仓库讨论 / 直接问 AI）。
